## 二、路线图

### P0 —— 补齐核心循环（✅ 2026-08-19 全部完成）

**1. ✅ 物品掉落与拾取**
- `drops.js`：生存挖掘 → 旋转小方块实体（复用手持几何+按 id 缓存），重力/弹跳/2.2 格磁吸/1.1 格拾取入栏+音效提示；上限 80；创造即挖即得
- 光照着色同步：掉落物亮度随所在格天光/块光实时变化
- 验证：node-gameplay-test.mjs [A]/[E]（挖掘→拾取→库存、物理稳定）

**2. ✅ 简易生存模式**
- `health.js`：10 心（20 血）CSS 绘制红心 HUD（不依赖 emoji 字体）、受伤红闪、跌落 >3.5 格伤害、死亡遮罩+茶会重生、脱战 8s 缓慢回血
- 创造/生存：标题菜单 + G 键切换；生存禁飞、挖掘间隔 520ms、放置消耗库存（角标计数）
- 验证：node-gameplay-test.mjs [B]/[C]/[D]（消耗/拒绝/跌落/死亡/重生/回血/禁飞）

**3. ✅ 世界种子与随机生成**
- `noise.js`：WORLD_SEED（URL ?seed= > v2 存档 > v1 迁移(=0，地形逐字节一致) > 随机），rnd2 加盐；vnoise3 支持洞穴
- 标题种子输入框（数字/文字皆可）+「🎲 新世界」双击确认；生物分布随种子
- 顺手修复 A6：重置/换种子被 pagehide 自动保存覆盖的上线以来潜伏 bug
- 验证：node-harness [1]（同种子逐字节一致/迁移/文字哈希）

**4. ✅ 洞穴与矿石**
- `carveCaves`：双频带 vnoise3 交叠阈值 .085 → 隧道网（仅地表下 ≥4 格，表面完整）；`seedOres`：噪声团块按深度分萤石糖(y≤28)/星光钻(y≤23)/红心宝石(y≤13)；`lampCaves`：洞底稀疏萤火菌灯（自带光+柔光）
- 新方块 4 种（OREG/ORES/OREH/TORCH），图集扩至 30 槽；快捷栏 26 格
- 验证：node-harness [2]（腔体 5.8k/三矿计数/深度约束/表面完整）

**5. ✅ 点光源光照**
- `light.js`：天光列扫描+BFS、块光 lum BFS（0-15）；`onWorldEdit` 半径 16 全高局部重光+标脏
- `mesher.js`：天光烘进顶点色（洞底 0.08 保底）、块光 `bl` 顶点属性、`onBeforeCompile` 注入三材质：`×max(uSkyF, bl×暖色)`——夜晚天光 0.13，火把/萤石/发光蘑菇真正照亮四周（实测夜景平均亮度 30/255）
- 区块重建分帧（每帧 3 个按距离排序），编辑无卡顿
- 验证：node-harness [3]/[4]/[5]（传播衰减 14→13→12、局部重光、属性对齐）+ 浏览器夜景像素实测

> P0 期间额外收获：A6 重置失效、A7 全屏 resize 丢失两个确认 bug 修复；`?debug=1` 状态条；
> Node 无头回归 61 项断言建立（见 CODE_ANALYSIS.md C6）
